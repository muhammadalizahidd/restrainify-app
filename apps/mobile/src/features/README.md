# Mobile Features

Feature folders should follow product ownership, not generic technical categories.

Recommended V1 folders:

- `auth`
- `onboarding`
- `dashboard`
- `protection`
- `screenTime`
- `recovery`
- `burst`
- `settings`
- `fapTracker`
- `sync`

React Native feature code may call the native bridge, but must not bypass native ownership for enforcement-affecting behavior.
